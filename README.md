# Yukon Docs

Public authoring notes for Yukon benchmark repositories.

Start with [`docs/github-actions-benchmark-author-guide.md`](docs/github-actions-benchmark-author-guide.md) when creating or reviewing a GitHub Actions-backed benchmark. It covers:

- single-track `schemaVersion: 1` manifests;
- multi-track `schemaVersion: 2` manifests;
- editable-path and score-artifact contracts;
- workflow dispatch requirements; and
- runner/security checks used by current self-hosted benchmark tracks.
